
Auto Clicker - clicker.py

A simple Python-based auto clicker for Windows. This tool allows you to automatically click at a specific position or at your current mouse cursor location at a customizable interval. Designed for personal use and lightweight automation tasks.

🚀 Features

Set a specific click position or use the current cursor location

Start and stop automatic clicking

Customize the click interval (in seconds)

Show the current mouse position

User-friendly command-line interface

Safe and easy to use, with Ctrl+C support to stop

⚙️ Requirements

Python 3.x

pyautogui
 library

Install dependencies using pip:

pip install pyautogui

📝 Usage

Run the program:

python clicker.py


Follow the on-screen menu:

1 - Set a new click position
2 - Show current mouse position
3 - Start auto clicker
4 - Stop auto clicker
5 - Change click interval
0 - Exit


Confirm actions as prompted. For example, when starting the auto clicker, it will ask for confirmation.

Stop the auto clicker anytime with option 4 or by pressing Ctrl+C.

⏱ Example Workflow

Set the click position (1)

Adjust the click interval (5 for example)

Start the auto clicker (3)

Let it run automatically at the chosen interval

Stop the auto clicker (4)

⚠️ Notes

This program is designed for Windows, but it may work on Linux/macOS with adjustments.

Use responsibly; excessive automated clicks may trigger software limitations.
